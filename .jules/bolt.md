## 2024-06-06 - Deferring below-the-fold rendering with React.lazy and IntersectionObserver
**Learning:** `React.lazy` combined with `Suspense` is good for bundle splitting, but it triggers network fetches immediately if rendered unconditionally. To defer network requests until components enter the viewport, an `IntersectionObserver` wrapper is required. However, there are three critical failure points: 1) The wrapper must be placed *inside* the element carrying the structural `id` to prevent breaking anchor navigation. 2) Removing the `minHeight` fallback prematurely upon intersection causes severe Cumulative Layout Shift (CLS) because the network fetch takes time. 3) `useRef` values used in `useEffect` for the observer target must be copied to a local variable before cleanup to avoid stale reference errors.
**Action:** When lazy-loading below-the-fold components, conditionally render them inside individual `<Suspense>` boundaries wrapped by a custom component using `IntersectionObserver`. Ensure the custom wrapper is placed inside the semantic `<section id="...">` element. Always define a fallback `minHeight` prop and maintain it permanently (or until fully rendered) to avoid CLS, and capture `ref.current` locally in `useEffect` cleanups.
