## 2024-06-21 - Intersection Observer Lazy Loading
**Learning:** React.lazy and Suspense by themselves trigger immediate network requests for components when they are grouped or rendered unconditionally in App.jsx. This negates the benefit of code splitting for components that are "below the fold" (not visible on initial load).
**Action:** Use an `IntersectionObserver` wrapper component (`LazySection`) along with `React.lazy` and `Suspense` for individual below-the-fold sections. Crucially, the wrapper MUST retain an estimated `minHeight` prop permanently to prevent layout shift (CLS) when the loading placeholder swaps with the resolved component. Also, the wrapper must be placed *inside* structural element holding the id (e.g. `<section id='Productos'>`) so it doesn't break single-page anchor navigation.
