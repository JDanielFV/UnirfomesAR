## 2025-05-30 - Lazy Loading and Anchor Links
**Learning:** Using `React.lazy` unconditionally in a single-page app with scroll-based navigation (anchor links) still triggers immediate bundle fetches. To truly defer loading, components must be conditionally rendered using `IntersectionObserver` (e.g., via a `LazySection` wrapper). Furthermore, placing lazy wrappers *around* the elements carrying `id` attributes removes them from the DOM before they load, breaking anchor link navigation. The lazy wrapper must be placed *inside* the structural element with the `id`. Finally, a `minHeight` must be set on the wrapper to minimize Cumulative Layout Shift (CLS).
**Action:** Always verify how lazy loading impacts DOM structure and use conditional rendering with an `IntersectionObserver` wrapper (like `LazySection`) placed *inside* anchor targets, supplying an estimated `minHeight` to prevent layout shifts.
