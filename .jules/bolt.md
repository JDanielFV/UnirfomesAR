## 2024-06-13 - [Preventing CLS with Lazy Loading Components]
**Learning:** When unconditionally rendering React.lazy components within a single grouped Suspense boundary or without placeholders, it triggers immediate network fetches for below-the-fold components, causing waterfall blocking and degrading initial load performance. Additionally, using an IntersectionObserver to lazy-load these components and immediately removing a `minHeight` fallback when intersecting causes a severe Cumulative Layout Shift (CLS) because the network fetch takes time, temporarily collapsing the container.
**Action:** Always conditionally render below-the-fold lazy components using an `IntersectionObserver` wrapper (e.g., `LazySection`) with individual `<Suspense>` boundaries. Maintain the estimated `minHeight` permanently on the wrapper or until the child component has fully rendered to prevent CLS during the fetch delay.
