## 2024-10-24 - Lazy Loading Wrappers and Layout Shifts
**Learning:** When implementing lazy loading wrappers (like `LazySection`) with `IntersectionObserver` and `React.lazy`, do not dynamically change the wrapper's `minHeight` to 'auto' immediately upon intersection. The network fetch triggered by `Suspense` takes time, and removing the minimum height prematurely collapses the container to 0px, causing a severe Cumulative Layout Shift (CLS) regression. Additionally, placing lazy loading wrappers outside the structural element carrying the anchor `id` attribute removes the anchor from the DOM before it loads, breaking single-page navigation.
**Action:** Maintain the `minHeight` on lazy wrappers permanently or until the child component has fully rendered. When wrapping sections targeted by anchor links, ensure the wrapper is placed *inside* the structural element carrying the `id` attribute (e.g., `<section id='Productos'>`). In React `useEffect` hooks that utilize `useRef` for DOM elements, assign `ref.current` to a local variable inside the effect before using it in the cleanup return function to prevent stale references.
