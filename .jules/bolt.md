## 2025-06-15 - Deferring below-the-fold component loading with IntersectionObserver
**Learning:** While `React.lazy` and `Suspense` can split bundles, unconditional rendering triggers immediate network fetches. To truly defer loading until components enter the viewport and prevent waterfall blocking on initial paint, conditionally rendering them using an `IntersectionObserver` wrapper is highly effective. However, doing so without maintaining a `minHeight` on the wrapper causes a severe Cumulative Layout Shift (CLS) regression when the `minHeight` is prematurely removed upon intersection before the child fully renders.
**Action:** When implementing lazy loading wrappers (like `LazySection`) with `IntersectionObserver` and `React.lazy`, conditionally render them and use individual `<Suspense>` boundaries. Crucially, maintain the `minHeight` permanently or until the child component has fully rendered to avoid CLS regressions, and place the wrapper *inside* any structural element carrying an `id` attribute to ensure anchor links function correctly before the component loads.
