## 2024-05-14 - Native Lazy Loading in Conditionally Rendered Modals
**Learning:** Adding native lazy loading (`loading="lazy"`) to image-heavy components like galleries, especially when they are hidden within interactive or conditionally rendered components like modals, significantly reduces the initial network payload and prevents massive unnecessary network requests until the user actually opens the modal. Additionally, in React, using unique identifiers like image URLs (`img`) as `key` instead of indices (`idx`) improves rendering performance by avoiding unnecessary re-renders when list items change.
**Action:** When implementing image galleries or any component with many images, especially those initially hidden (e.g., in modals or below the fold), always apply `loading="lazy"` to `img` tags. Furthermore, prioritize using unique string identifiers as React keys over array indices.
