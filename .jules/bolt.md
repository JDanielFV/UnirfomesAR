## 2024-05-18 - True Deferred Loading and CLS Prevention with IntersectionObserver and Suspense
**Learning:** Using React.lazy and Suspense for below-the-fold components in this codebase splits the bundle, but unconditional rendering triggers immediate network fetches. Additionally, lazy loading wrappers must maintain a permanent `minHeight` prop; immediately changing it to 'auto' upon intersection causes a 0px collapse before the component renders via Suspense, leading to severe Cumulative Layout Shift (CLS).
**Action:** When lazy loading components targeted by anchor links, unconditionally render the anchor (e.g. `<section id='Productos'>`) but wrap the inner component in an `IntersectionObserver` wrapper (like `<LazySection>`) that maintains a permanent `minHeight` equal to the expected component height to prevent CLS.
