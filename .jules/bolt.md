## 2025-02-14 - Lazy loading layout shift and anchor links preservation
**Learning:** When adding `React.lazy` and `Suspense` for below-the-fold components, grouping them all inside a single Suspense block or unconditionally rendering them triggers immediate network requests, defeating the purpose of lazy loading. A wrapper that uses `IntersectionObserver` must be conditionally rendered. Additionally, it is critical not to remove the estimated `minHeight` on the container immediately upon intersection, because the network fetch via `Suspense` takes time and collapsing the container to 0px creates a massive Cumulative Layout Shift (CLS). Finally, the Intersection Observer wrapper must be placed *inside* structural anchor elements (e.g., `<section id="...">`); otherwise, the ID attribute is not present in the DOM when the user clicks a nav link, completely breaking single-page scroll navigation.
**Action:** Always conditionally render lazy components when they intersect the viewport (using `IntersectionObserver` with a `rootMargin`), maintain a stable `minHeight` permanently on the wrapper to prevent CLS regressions, and place the lazy wrapper *inside* any wrapper container that holds navigation IDs.
