## 2025-05-28 - Optimizing Below-the-fold with IntersectionObserver
**Learning:** Using `React.lazy` inside a single top-level Suspense boundary still triggers immediate network requests for all components inside it because it mounts them simultaneously. Furthermore, adding conditional loading wrappers *around* section anchor wrappers breaks in-page anchor links since the IDs do not exist in the DOM until the component loads.
**Action:** Always conditionally render lazy components specifically tied to scroll position using an `IntersectionObserver` wrapper (like `LazySection`). To preserve navigation anchors, ensure that the wrapper component is nested *inside* the structural HTML element that holds the section's `id` attribute, and pass a calculated `minHeight` parameter to mitigate Cumulative Layout Shift (CLS) when loading occurs.
