## 2025-02-06 - Deferring Below-the-fold Renderings with React.lazy and IntersectionObserver
**Learning:** In Single Page Applications where section `id`s are used as anchor links, unconditionally using `React.lazy` inside grouped boundaries triggers all network fetches immediately. Additionally, wrapping the `id` bearing sections themselves with the IntersectionObserver's container removes the section from DOM before render, breaking single-page navigation. Also, immediately resetting `minHeight` of placeholder containers upon intersection without awaiting Suspense results in severe Cumulative Layout Shifts (CLS).
**Action:** Always conditionally fetch components with `IntersectionObserver` instead of just using generic `React.lazy`. Use a `LazySection` wrapper *inside* the structural HTML tags (e.g. `<section>`) carrying the anchor IDs so they exist in the DOM from start, and ensure the wrapper maintains a predefined `minHeight` permanently or until the child fully mounts.
