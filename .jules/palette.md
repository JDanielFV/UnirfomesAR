## 2024-05-15 - Improving Custom Modal Accessibility and UX
**Learning:** Custom modal overlays need complete accessibility features to ensure smooth interaction and screen-reader usability. Simply implementing a close button is insufficient for a good user experience; modals should close intuitively via the "Escape" key and clicking outside the modal content. Furthermore, semantic tags like `role="dialog"` and `aria-modal="true"` are necessary for screen readers to recognize the modal context.
**Action:** When creating or updating custom modal overlays, always attach a global `keydown` event listener for "Escape", implement `e.target === e.currentTarget` on the overlay's `onClick` handler to handle click-to-close behavior, and apply proper semantic attributes (`role="dialog"`, `aria-modal="true"`) to the modal content container. Also, ensure interactive elements within the modal have appropriate `aria-label`s.
