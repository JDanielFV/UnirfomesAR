## 2026-06-14 - Custom Modal Accessibility Patterns
**Learning:** Custom modals require specific semantic attributes (`role="dialog"`, `aria-modal="true"`) to be properly identified by screen readers. Furthermore, keyboard accessibility (like closing the modal via the "Escape" key) and mouse interaction patterns (like clicking outside the modal content to close) are essential UX features that are often missed. Additionally, relying solely on array indices as keys in React lists can cause rendering bugs; when mapping non-unique strings like image paths, a composite key (e.g., `${img}-${idx}`) ensures stable identities.
**Action:** Always implement comprehensive accessibility attributes and keyboard/mouse closing mechanisms for custom overlay components. Ensure robust React key generation for mapped elements to maintain predictable UI state.
