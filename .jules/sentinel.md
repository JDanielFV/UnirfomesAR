## 2024-07-09 - Prevent Reverse Tabnabbing in External Links
**Vulnerability:** External links created with `target="_blank"` without `rel="noopener noreferrer"` expose the site to reverse tabnabbing attacks, where the newly opened tab can gain partial access to the original window's `window.opener` object, potentially navigating it to a malicious URL.
**Learning:** Found several external links (e.g., Google Maps, WhatsApp, Facebook, app stores) in `Contacto.jsx`, `Footer.jsx`, and `PromoApp.jsx` using `href` without proper tabnabbing protections. In React/JSX, setting external destinations directly in `<a>` tags requires adding `target="_blank" rel="noopener noreferrer"` to secure the cross-origin navigation.
**Prevention:** Always add `target="_blank" rel="noopener noreferrer"` to external `href` links to safely open external content. Exclude `tel:` and `mailto:` protocols as these trigger native application handlers and opening blank tabs for them is a UX anti-pattern.
