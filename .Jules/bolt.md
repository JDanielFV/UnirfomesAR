## 2026-05-19 - Adding lazy loading to image galleries
**Learning:** Found that the `ModalGallery` component mapped over a large array of images (`galleryImages`) without lazy loading, which causes the browser to fetch all 31+ high-resolution images simultaneously on the initial page load, potentially blocking the main thread and increasing the initial payload significantly even though the gallery is not immediately visible. Attempted to wrap the mapped elements in a `<React.Fragment>` purely to add a JSX comment before the element, which is unidiomatic, clunky, and risks a `ReferenceError: React is not defined` at runtime if `React` is not explicitly imported (as is common in modern React 17+ codebases).
**Action:** Always add `loading="lazy"` to `img` tags (or their styled component equivalents like `GalleryImg`) mapping over multiple images to defer network requests until they enter the viewport. Do not wrap mapped elements in `<React.Fragment>` purely to add a comment; instead, place block comments (`/* ... */`) directly inside the component's props to ensure valid JSX syntax without breaking React semantics or requiring explicit imports.
