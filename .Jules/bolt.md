## 2025-05-24 - Lazy Loading Below-the-fold with IntersectionObserver
**Learning:** Using `React.lazy` and `<Suspense>` alone at the root level unconditionally triggers immediate network fetches for the chunks, negating the performance benefits of deferring below-the-fold content. Wrapping them in a conditional `IntersectionObserver` component (`LazySection`) truly defers the fetch until the elements approach the viewport. However, this wrapper must be placed *inside* the structural element carrying the anchor `id` (e.g., `<section id='Productos'>`). If the `id` itself is conditionally rendered or wrapped inside the lazy block, it breaks single-page anchor navigation because the target element does not exist in the DOM when the link is clicked.
**Action:** Always place the structural anchor `id` outside the lazy loading wrapper (e.g., `<section id="target"><LazyWrapper>...</LazyWrapper></section>`) and use a `minHeight` fallback to minimize Cumulative Layout Shift (CLS) while ensuring navigation targets exist immediately on load.
